What I do

I work both sides of the instrument. I run TIRF, widefield and MINFLUX experiments, and I write the models that interpret them. That combination is why I tend to find the problems sitting between the hardware and the analysis — the ones where the pipeline runs fine and the answer is still wrong.

PhD in Chemistry from the University of Illinois Urbana-Champaign, now a postdoc at UC Irvine working on ion channel dynamics in human stem-cell-derived cells. Six years of building deep learning and statistical methods for imaging data, with the code packaged, tested and handed to other people.

Looking for algorithm developer, computational scientist, image analysis and machine learning roles in scientific instruments, metrology, biotech and pharma.

Software

AUDĒNS

Desktop application for real-time gold nanoparticle shape classification and size estimation from dark-field scattering spectra. I built the interface over the trained CNN so experimentalists run inference at the microscope without writing code.

Python · TensorFlow · Tkinter · code release on publication

spt-classify

Motion-type classification for 3D single-particle tracking. Six interpretable descriptors, a bagged ensemble, a trajectory simulation suite, and tests that check physics rather than array shapes. Continuous integration across three Python versions, containerised with Docker.

Python · scikit-learn · Docker · MIT

3D-SPT-Classification

MATLAB reference implementation of the published method: feature selection by mRMR, NCA and ReliefF with Bayesian hyperparameter optimization.

MATLAB · MIT
